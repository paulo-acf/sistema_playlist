# **README**



### Este projeto consiste no desenvolvimento de um sistema de backend para um aplicativo de músicas.

### 

### O sistema permite gerenciar uma biblioteca de músicas, organizar filas de reprodução por humor e consultar o histórico de músicas reproduzidas.

### 

### Numa tentativa de tornar este projeto mais didático, foram acrescentados comentários junto ao código (a ideia é tentar facilitar o entendimento e uma futura revisão — “A revisão é a mãe da retenção.”).



## **• Para clonar o repositório:**



#### ```bash

#### git clone https://github.com/paulo-acf/sistema\_playlist

#### ```



## **• Para executar o projeto:**



#### ```bash

#### python main.py

#### ```
